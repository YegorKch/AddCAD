# AutoCad utilits

Утилиты и надстройки для AutoCAD.

```
AutoCad utilits\
├── AddCAD\                     свой набор надстроек  → см. AddCAD\README.md
├── Резервные копии\            бэкапы реестра и оригиналов блоков
├── GeomProps2025x64.arx        \ одиночные сторонние утилиты
└── NumInc V3.9 .lsp            /
```

---

## AddCAD

Собственный набор надстроек: одна вкладка ленты **AddCAD**, внутри панели
по утилитам. Сейчас утилита одна — **Рамки**: форматы А0–А4 горизонтально
и вертикально, плюс штамп.

Установка — запустить `AddCAD\AddCAD-Setup.bat` при закрытом AutoCAD.
Команды, устройство и как добавить следующую утилиту — в `AddCAD\README.md`.

Канонические команды идут с префиксом `А` (`АРАМКА`, `АШТАМП`, `АМАСШТАБ`),
короткие оставлены алиасами.

## Сторонние утилиты

Лежали в папке раньше, к AddCAD отношения не имеют. Обе грузятся
командой `ЗАГРУЗИТЬПРИЛОЖЕНИЕ` (`APPLOAD`):

| Файл | Что это |
|---|---|
| `GeomProps2025x64.arx` | ARX-модуль под AutoCAD 2025 x64 |
| `NumInc V3.9 .lsp` | нумерация с приращением |

## Резервные копии

**`acad2025_profile_backup.reg`** — экспорт ветки
`HKCU\Software\Autodesk\AutoCAD\R25.0\ACAD-8101:419`, снятый **до** правок
профиля 05.09.2026. Двойной клик возвращает настройки AutoCAD к исходному
состоянию. Делать **только при закрытом AutoCAD** — иначе он перезапишет
ветку своими значениями при выходе.

Что правилось в профиле:

- в пути поиска добавлен `C:\Program Files\Autodesk\AutoCAD 2025\Support`
  (без него не находились словари, отсюда была ошибка «Не найден основной
  словарь»);
- `MainDictionary` переключён на `rus`;
- удалены `AppLogFileFullPath` (битый путь `" C:\Temp\RELEAS~2\app.log"`
  с ведущим пробелом) и `AppLogLevel = debug` — остатки чужого
  импортированного профиля;
- в `TRUSTEDPATHS` добавлен путь плагина AddCAD.

Отдельно есть `Profile.aws.addcad.bak` рядом с самим `Profile.aws`
в профиле AutoCAD — на случай, если поедет вкладка ленты.

**`Blocks_оригинал_menuGEO\`** — исходные 11 DWG рамок из menuGEO, как они
были до обезличивания и до пересохранения в формат 2018. Пригодятся, если
понадобится вернуть авторские надписи или совместимость со старым AutoCAD.

## Планы
