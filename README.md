# AddCAD

Набор надстроек для AutoCAD. Одна вкладка ленты **AddCAD**, внутри — панели
по утилитам. Сейчас утилита одна: **Рамки** — форматы А0–А4 в альбомной
и книжной ориентации плюс штамп.

Плагин на LISP + CUIX, без .NET и Visual Studio. Проверен на AutoCAD 2025
с русским интерфейсом.

## Установка

Закрыть AutoCAD → запустить `AddCAD\AddCAD-Setup.bat` → готово. Это один
самораспаковывающийся файл на 36 КБ; он же прописывает доверенный путь
во все найденные профили AutoCAD, чтобы не кликать «всегда загружать».

Путь установки самого AutoCAD значения не имеет — плагин кладётся в папку
профиля Windows, которую AutoCAD сканирует сам. Нужно лишь, чтобы AutoCAD
хотя бы раз запускался под этой учётной записью.

Готовый установщик — на [странице релизов](https://github.com/YegorKch/AddCAD/releases/latest),
подробности и удаление — в [AddCAD/README.md](AddCAD/README.md).

## Команды

Канонические имена идут с префиксом **А**, короткие оставлены алиасами:

| Канон | Алиасы | Что делает |
|---|---|---|
| `АРАМКА` / `ARAMKA` | `РАМКА`, `RAMKA` | вставка рамки с выбором формата |
| `АШТАМП` / `ASHTAMP` | `ШТАМП`, `SHTAMP` | штамп на отдельный слой |
| `АМАСШТАБ` / `ASCALE` | `РАМКАМАСШТАБ`, `RAMKASCALE` | режим масштабирования |
| `АВПИСАТЬ` / `AFIT` | `ВПИСАТЬ` | подогнать надписи под свои графы |

Быстрая вставка — `Р0А`…`Р4А` для альбомных, `Р0К`…`Р4К` для книжных;
латиницей `R0L`…`R4L` и `R0P`…`R4P`. Прежние `Р0Г` / `Р0В` остались
синонимами.

Рамка висит на курсоре, пока не укажешь точку, дальше масштабируется от неё
мышью или вводом числа. Вставленная рамка сразу взрывается, определение
блока вычищается — лишних блоков в чертеже не остаётся.

## Как устроены рамки

Рамки не хранятся файлами — они **строятся кодом** по размерам стандарта:
ГОСТ 2.301 задаёт форматы листов, ГОСТ 2.104 — основную надпись. Плагин
собирает определение блока в чертеже на лету, ставит его, взрывает
и вычищает за собой.

Отсюда три следствия: в комплекте нет ни одного DWG, работает любая версия
AutoCAD, а весь установщик занимает 36 КБ. Все размеры лежат одним списком
в начале `Ramki.lsp`, так что геометрия правится одной строкой.

В штампе рисуются графы по ГОСТ 2.104 — Должность, Ф.И.О., Подпись, Дата,
Лист/Листов. В заполняемых графах стоит заготовка «ТЕКСТ»: она привязана
серединой к центру ячейки, поэтому вписанное вами остаётся отцентрованным
и не вылезает за линии.

Если текста много, плагин сам уменьшает высоту шрифта, пока надпись
не уложится в графу, и возвращает её обратно, когда текст сократили.
Чужой текст в чертеже это не затрагивает — подгоняются только надписи,
поставленные самим плагином.
