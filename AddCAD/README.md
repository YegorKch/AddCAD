# AddCAD 1.0.0

Набор надстроек для AutoCAD. Одна вкладка ленты «AddCAD», внутри — панели
по утилитам. Сейчас утилита одна: **Рамки** (форматы А0–А4 и штамп).

---

## Установка

**Быстро:** закрыть AutoCAD → запустить `AddCAD-Setup.bat` → готово.

Один файл, 231 КБ, ничего кроме Windows не требует: внутри него лежит
дистрибутив в base64, он сам распаковывается во временную папку и ставится.
Его и надо переносить на другой компьютер.

**Вручную:** распаковать `AddCAD-1.0.0.zip` (или взять папку `Плагин\`),
запустить `install.bat`.

**Совсем вручную:** скопировать `Плагин\AddCAD.bundle` в
`%APPDATA%\Autodesk\ApplicationPlugins\` и добавить
`…\AddCAD.bundle\Contents\...` в доверенные местоположения
(команда `ДОВПУТИ`). Без этого при `SECURELOAD = 1` AutoCAD откажется
грузить LISP.

Установщик прописывает доверенный путь во **все** найденные профили всех
версий AutoCAD, поэтому кликать «всегда загружать» не приходится.

**Удаление:** `uninstall.bat` внутри `AddCAD.bundle`.

## Имена команд

Канонические команды идут с префиксом **А** — он отделяет команды AddCAD
от чужих надстроек. Короткие имена оставлены алиасами, ими удобно
пользоваться, пока не столкнулись с чем-то ещё.

| Канон | Алиасы | Что делает |
|---|---|---|
| `АРАМКА` / `ARAMKA` | `РАМКА`, `RAMKA` | вставка рамки с выбором формата |
| `АШТАМП` / `ASHTAMP` | `ШТАМП`, `SHTAMP` | штамп на отдельный слой «Штамп» |
| `АМАСШТАБ` / `ASCALE` | `РАМКАМАСШТАБ`, `RAMKASCALE` | режим масштабирования |

Быстрая вставка — намеренно без префикса, они и так почти не конфликтуют:

```
Р0Г Р1Г Р2Г Р3Г Р4Г     горизонтальные
Р0В Р1В Р2В Р3В Р4В     вертикальные
R0G … R4V               то же латиницей
```

## Как работает вставка

Рамка висит на курсоре, пока не укажешь точку — сразу видно, как она
встанет. Дальше включается масштабирование от этой точки: тяни мышью
и смотри результат либо введи число с клавиатуры.

`АМАСШТАБ` переключает режим. По умолчанию масштаб динамический; если
задать число, рамка вставляется сразу нужного размера и на курсоре
появляется уже отмасштабированной.

Рамка вставляется из DWG, сразу взрывается, определение блока вычищается —
лишних блоков в чертеже не остаётся. Надписи «Лист / Листов / 1 / 1»
дочерчиваются кодом на месте, с учётом фактического масштаба: ячейки
ищутся геометрически, поэтому одинаково работает для всех форматов.

## Как добавить следующую утилиту

Структура рассчитана на рост. Для новой утилиты нужно:

1. Папка `Contents\<Утилита>\` с её `.lsp` и ресурсами.
2. В `PackageContents.xml` — по строке `Support Path` на каждую папку
   с ресурсами плюс `ComponentEntry` на сам `.lsp`.
3. В `build_cuix.py` — своя `RibbonPanelSource` и ссылка на неё
   в `RibbonTabSource`; вкладка остаётся одна.
4. Команды называть с префиксом `А`.

## Про рамки

Блоки взяты из **menuGEO** (`C:\Program Files (x86)\menuGEO\support`).
Выяснилось, что рамки там — просто DWG, вставляемые макросом кнопки, без
всякого кода; поэтому вместо выдёргивания кусков menuGEO собран
самостоятельный плагин.

**Штампы обезличены:** всё содержательное заменено на «ТЕКСТ», остались
только графы по ГОСТ 2.104 — `Должность`, `Ф.И.О.`, `Подпись`, `Дата`,
`Формат`, `Лист`/`Листов`. Формы рамок и штампов заданы стандартом,
а конкретные формулировки были авторскими — после обезличивания вопрос
о заимствовании снимается.

Оригиналы лежат в `..\Резервные копии\Blocks_оригинал_menuGEO\`.

Рамки пересохранены в формате DWG 2018 (было 2007) — заодно похудели
с 70 КБ до 19,6 КБ. На AutoCAD старше 2018 не откроются.

menuGEO остаётся установленным, плагины не конфликтуют.

## Пересборка

```
python "Исходники сборки\make_icons.py" icons
python "Исходники сборки\build_cuix.py" icons Плагин\AddCAD.bundle\Contents\AddCAD.cuix
python "Исходники сборки\makezip.py" Плагин AddCAD-1.0.0.zip AddCAD
python "Исходники сборки\make_selfextract.py" AddCAD-1.0.0.zip AddCAD-Setup.bat
```

| Файл | Назначение |
|---|---|
| `Ramki_src_utf8.lsp` | **исходник команд**, правится он; в плагин кладётся перекодированным в CP1251 |
| `make_icons.py` | иконки BMP 32 бита, без сторонних библиотек |
| `build_cuix.py` | сборка `.cuix` (это zip с XML-секциями) |
| `makezip.py` | упаковка дистрибутива |
| `make_selfextract.py` | вшивание zip в `.bat` через base64 |
| `checkparens.py` | проверка баланса скобок в LISP |
| `preview.py` | склейка иконок в увеличенный лист для проверки глазом |
| `add_tab_to_ws.py` | прописать вкладку в рабочее пространство, если не появилась |
| `Ramki_texts.lsp` | разовая утилита обезличивания штампов (уже применена) |

Перекодировка после правки исходника:

```
iconv -f UTF-8 -t CP1251 Ramki_src_utf8.lsp > ...\Contents\Ramki\Ramki.lsp
```

работы — в `..\CLAUDE.md` и `..\Git.md`. Заметки Claude Code про эту
