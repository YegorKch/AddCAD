# AddCAD 1.1.0

Набор надстроек для AutoCAD. Одна вкладка ленты «AddCAD», внутри — панели
по утилитам. Сейчас утилита одна: **Рамки** (форматы А0–А4 и штамп).

---

## Установка

Закрыть AutoCAD → запустить `AddCAD-Setup.bat` → готово. Один файл, 36 КБ,
ничего кроме Windows не требует: внутри него дистрибутив в base64, он сам
распаковывается во временную папку и ставится. Его и переносят на другие
компьютеры.

**Удаление:** запустить тот же `AddCAD-Setup.bat` — если AddCAD уже стоит,
он предложит переустановить, удалить или выйти. Удаление уносит папку плагина
и обе записи, которые установщик сделал в профиле AutoCAD: доверенный путь
и путь поиска. Чертежи не затрагиваются: вставленные рамки — обычные линии
и текст, они останутся и без плагина.

Отдельный `uninstall.bat` внутри `AddCAD.bundle` тоже работает и делает
то же самое, но искать его в `%APPDATA%` незачем.

### Как он находит AutoCAD

Никак — и это правильно. Путь установки AutoCAD установщику не нужен:

1. Bundle копируется в `%APPDATA%\Autodesk\ApplicationPlugins\` — это папка
   профиля Windows, а не AutoCAD. AutoCAD сам сканирует её при запуске,
   где бы он ни был установлен.
2. Доверенный путь прописывается в реестре, обходом всех профилей в
   `HKCU\Software\Autodesk\AutoCAD\<версия>\<продукт>\Profiles`. Без этого
   при `SECURELOAD = 1` AutoCAD отказался бы грузить LISP, а так кликать
   «всегда загружать» не приходится.
3. Туда же, в профиль, дописывается путь поиска до папки плагина — иначе
   лента не находит картинку своей кнопки. Дописывается только своя строка,
   чужие пути не трогаются; при удалении она убирается.

Единственное условие: **AutoCAD должен быть хотя бы раз запущен** под этой
учётной записью Windows — иначе ветки профиля в реестре ещё нет и доверенный
путь писать некуда. Установщик про это предупредит и попросит повторить.

Для другой учётной записи установку надо прогнать под ней: и папка плагинов,
и ветка реестра — свои у каждого пользователя.

## Имена команд

Канонические команды идут с префиксом **А** — он отделяет команды AddCAD
от чужих надстроек. Короткие имена оставлены алиасами, ими удобно
пользоваться, пока не столкнулись с чем-то ещё.

| Канон | Алиасы | Что делает |
|---|---|---|
| `АРАМКА` / `ARAMKA` | `РАМКА`, `RAMKA` | вставка рамки с выбором формата |
| `АШТАМП` / `ASHTAMP` | `ШТАМП`, `SHTAMP` | штамп на отдельный слой «Штамп» |
| `АМАСШТАБ` / `ASCALE` | `РАМКАМАСШТАБ`, `RAMKASCALE` | режим масштабирования |
| `АВПИСАТЬ` / `AFIT` | `ВПИСАТЬ` | подогнать надписи под свои графы |
| `АВТОВПИСАТЬ` / `AUTOFIT` | — | включить или выключить автоподгонку |

Быстрая вставка — намеренно без префикса, они и так почти не конфликтуют:

```
Р0А Р1А Р2А Р3А Р4А     альбомные
Р0К Р1К Р2К Р3К Р4К     книжные
R0L … R4L, R0P … R4P    то же латиницей
```

Прежние `Р0Г`…`Р4В` и `R0G`…`R4V` работают как синонимы: ориентации
переименовали, а привычку ломать незачем.

## Как работает вставка

Рамка висит на курсоре, пока не укажешь точку — сразу видно, как она
встанет. Дальше включается масштабирование от этой точки: тяни мышью
и смотри результат либо введи число с клавиатуры.

`АМАСШТАБ` переключает режим. По умолчанию масштаб динамический; если
задать число, рамка вставляется сразу нужного размера и на курсоре
появляется уже отмасштабированной.

Рамка строится кодом по размерам стандарта, вставляется, сразу взрывается,
а определение блока вычищается — лишних блоков в чертеже не остаётся.
Никаких DWG в комплекте нет: вся геометрия задана числами в `Ramki.lsp`,
поэтому плагин работает в любой версии AutoCAD и весит считаные килобайты.

## Как добавить следующую утилиту

Структура рассчитана на рост. Для новой утилиты нужно:

1. Папка `Contents\<Утилита>\` с её `.lsp` и ресурсами.
2. В `PackageContents.xml` — по строке `Support Path` на каждую папку
   с ресурсами плюс `ComponentEntry` на сам `.lsp`.
3. В `build_cuix.py` — своя `RibbonPanelSource` и ссылка на неё
   в `RibbonTabSource`; вкладка остаётся одна.
4. Команды называть с префиксом `А`.

## Про рамки

Рамки не хранятся файлами, а строятся кодом по размерам стандарта:
ГОСТ 2.301 (форматы листов) и ГОСТ 2.104 (основная надпись). Определение
блока собирается в чертеже на лету, вставляется, взрывается и вычищается,
так что остаются только линии и текст.

Все числа лежат в одном месте — в начале `Ramki_src_utf8.lsp`: размеры
форматов, поля 20/5, сетка штампа 185×55, веса линий и высоты шрифта.
Поменять что-то в геометрии — значит поправить там одну строку.

**В штампе рисуются только графы по ГОСТ 2.104** — `Должность`, `Ф.И.О.`,
`Подпись`, `Дата`, `Лист`/`Листов` и метка формата под рамкой.

В графах, которые заполняет специалист — обозначение, наименование и три
нижние, — стоит заготовка «ТЕКСТ». Она привязана серединой к центру ячейки
и имеет заданную ширину, поэтому вписанное остаётся отцентрованным,
а длинная строка переносится внутри ячейки, а не вылезает за линии.

### Автоподгонка высоты

Переноса мало: много текста всё равно вылезет вверх и вниз. Поэтому плагин
уменьшает высоту шрифта, пока надпись не уложится в графу, — шагами по 8%,
но не мельче 40% от исходной. Сократили текст обратно — высота вернётся.

Размеры графы плагин прячет в самой надписи (XDATA `ADDCAD`), поэтому
подгонка не зависит ни от места рамки в чертеже, ни от её масштаба:
значения типа 1041 AutoCAD масштабирует вместе с объектом. Проверено —
в рамке масштаба 5 графа 118×8 становится 590×40.

Работает автоматически: на каждую свою надпись плагин вешает объектный
реактор, тот помечает изменённую надпись, а подгонка выполняется по
окончании команды — менять объект прямо в обработчике его изменения
AutoCAD не позволяет.

**Чужой текст не затрагивается**: реактор висит только на надписях
с меткой `ADDCAD`. Подгоняется ровно та надпись, которую правили, —
соседние графы и другие рамки не пересчитываются.

Объектные реакторы не сохраняются в файле, поэтому при загрузке в чертёж
плагин находит свои надписи и вешает наблюдение заново. Ручной прогон —
`АВПИСАТЬ`, выключить автоматику — `АВТОВПИСАТЬ`.

### Шрифт и стиль текста

Надписи идут в собственном стиле плагина — **AddCAD**, а не в общем «ГОСТ».
В чужом чертеже стиль с таким именем может быть заведён под любой шрифт,
и рамка унаследовала бы его вид.

Шрифт выбирается по факту наличия, в таком порядке:

1. `GOST_Common Italic.ttf` — ставится вместе с некоторыми надстройками,
   есть не на каждой машине;
2. `isocpeur.ttf` — идёт в комплекте самого AutoCAD, по начертанию ближе
   всего к ГОСТ 2.304;
3. `simplex.shx` — подстраховка, есть всегда.

Если чертёж пришёл с машины, где нужного шрифта не было, при следующей
вставке плагин вернёт своему стилю правильный шрифт сам.

Ограничения по версии AutoCAD нет: рисовать умеет любая, где работает LISP.

## Пересборка

```
python "Исходники сборки\make_icons.py" icons
python "Исходники сборки\build_cuix.py" icons Плагин\AddCAD.bundle\Contents\AddCAD.cuix
python "Исходники сборки\makezip.py" Плагин AddCAD-1.1.0.zip AddCAD
python "Исходники сборки\make_selfextract.py" AddCAD-1.1.0.zip AddCAD-Setup.bat
del AddCAD-1.1.0.zip
```

| Файл | Назначение |
|---|---|
| `Ramki_src_utf8.lsp` | **исходник команд**, правится он; в плагин кладётся перекодированным в CP1251 |
| `make_icons.py` | иконки PNG с прозрачностью, без сторонних библиотек |
| `build_cuix.py` | сборка `.cuix` (это zip с XML-секциями) |
| `makezip.py` | упаковка дистрибутива (промежуточный zip, в репозиторий не идёт) |
| `make_selfextract.py` | вшивание zip в `.bat` через base64 |
| `checkparens.py` | проверка баланса скобок в LISP |
| `preview.py` | склейка иконок в увеличенный лист для проверки глазом |
| `add_tab_to_ws.py` | прописать вкладку в рабочее пространство, если не появилась |

Перекодировка после правки исходника:

```
iconv -f UTF-8 -t CP1251 Ramki_src_utf8.lsp > ...\Contents\Ramki\Ramki.lsp
```

AutoCAD вообще: структура bundle, `PackageContents.xml`, доверенные пути,

работы — в `..\CLAUDE.md` и `..\Git.md`. Заметки Claude Code про эту
машину (профиль AutoCAD, что правилось в реестре) хранятся в его памяти
и в репозиторий не входят.
