# Инструкция для Claude

Переносимая часть контекста: едет вместе с папкой и попадает в репозиторий.
Машинная конкретика (профиль AutoCAD, пути, что правилось в реестре) —
в памяти Claude Code, не здесь.

## Проект

Утилиты и надстройки для AutoCAD. Устройство папки — в [README.md](README.md),
сам плагин — в [AddCAD/README.md](AddCAD/README.md). Общий рецепт сборки
плагинов AutoCAD — в
[AddCAD/Документация/autocad-plugin-bundle-method.md](AddCAD/Документация/autocad-plugin-bundle-method.md).

## Общение

По-русски. Команды AutoCAD пользователь называет по-русски (`ПРОВЕРИТЬ`,
`МЕНЮЗАГР`, `ДОВПУТИ`) — так же и отвечать.

Пользователь — проектировщик инженерных сетей и геодезист, не программист:
в AutoCAD и в предметной области ориентируется уверенно, в разработке —
нет. Решённое не переобсуждать: если вариант уже согласован, делать.
Результат проверяет глазами, поэтому стоит явно писать, что должно
появиться на экране после изменений.

## Git

Правила — в [Git.md](Git.md), читать перед любыми действиями с git.
Коротко: Git здесь версионный бэкап, а не журнал правок. Коммиты крупные,
осмысленные. **Коммит, пуш и релиз — только по явной команде**, не по
своей инициативе и не «а давайте закоммитим».

Перед публикацией на GitHub внести в `.gitignore` папку
`Резервные копии/` — там экспорт ветки реестра с путями профиля.

## Работа с AutoCAD

**Любые правки реестра и `Profile.aws` — только при закрытом AutoCAD.**
При выходе AutoCAD перезаписывает свою ветку реестра и рабочее
пространство целиком, иначе правки пропадут.

Без доверенного пути (`ДОВПУТИ`, `TRUSTEDPATHS`) при `SECURELOAD = 1`
AutoCAD откажется грузить LISP плагина.

## Соглашения AddCAD

Канонические команды — с префиксом **А** (`АРАМКА`, `АШТАМП`, `АМАСШТАБ`),
он отделяет их от чужих надстроек. Короткие имена оставлены алиасами.
Быстрая вставка (`Р0Г`…`Р4В`) — намеренно без префикса.

Одна вкладка ленты «AddCAD», каждая новая утилита — своя панель внутри
неё и своя подпапка в `Contents`. Порядок добавления утилиты расписан
в [AddCAD/README.md](AddCAD/README.md).

## Сборка

Исходник команд — `AddCAD/Исходники сборки/Ramki_src_utf8.lsp`, правится
он. В плагин кладётся **перекодированным в CP1251** — `Ramki.lsp` внутри
bundle в UTF-8 работать не будет. Скрипты пересборки (`build_cuix.py`,
`makezip.py`, `make_selfextract.py`) и порядок вызова — в
[AddCAD/README.md](AddCAD/README.md).

Штампы в блоках **обезличены** — содержательные надписи заменены на
«ТЕКСТ», остались только графы по ГОСТ 2.104. Так сделано ради публикации,
обратно авторские формулировки не возвращать. Исходные версии блоков —
в локальной папке `Резервные копии/`, в репозиторий она не входит.

В публичных файлах репозитория не упоминаем сторонние надстройки,
установленные на этой машине, — ни в текстах, ни в комментариях кода.
